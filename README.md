# portifoloi-gerencias# NFT Card Gallery & Marketplace

Galeria responsiva de componentes NFT desenvolvida com HTML5, CSS3 (Grid e Flexbox) e animações CSS, expandindo o desafio original do Frontend Mentor.

🌐 **Link de Acesso:** [https://Higor552.github.io/portifoloi-gerencias/](https://Higor552.github.io/portifoloi-gerencias/)

##  Tecnologias Utilizadas
- **HTML5**
- **CSS3** (Grid, Flexbox, Variáveis CSS)
- **[Animate.style](https://animate.style/)**
- **[Leonardo.ai](https://app.leonardo.ai/)** (Geração de imagens e logo)
- **Git & GitHub Pages**

##  Funcionalidades
- Layout 100% responsivo para Mobile e Desktop.
- Componente de Header interativo.
- Efeitos de hover e animações de elevação nos cards.
- Coleção de cards alimentada por imagens de Inteligência Artificial.
